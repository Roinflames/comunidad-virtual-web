# Comunidad Virtual Web

Versión cero de sitio comercial para Comunidad Virtual.

## Ejecutar local

Abrir `index.html` directamente en navegador, o servir con cualquier servidor estático.

Ejemplo:

```bash
cd /home/rreyes/projects/comunidad-virtual-web
python3 -m http.server 8090
```

Luego abrir `http://localhost:8090`.
